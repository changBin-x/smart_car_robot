# 海康 USB 单目相机验证手册

本包封装 `usb_cam` 采集配置和 MJPEG 解码桥接节点。稳定设备别名为 `/dev/hik_monocular`：`usb_cam` 仅向内部 `/hik_monocular/driver/image_raw` 和 `/hik_monocular/driver/camera_info` 发布原始 MJPEG 缓冲及内参；`hik_mjpeg_decoder_node` 校验 JPEG 起止标记、丢弃坏帧，再向外部发布标准 BGR 图像和相机内参。

## 1. 前置条件

树莓派上安装驱动与标定工具：

```bash
sudo apt install -y ros-jazzy-usb-cam ros-jazzy-camera-calibration \
  ros-jazzy-web-video-server ros-jazzy-image-transport-plugins
```

首次部署时安装设备别名和 USB 缓冲参数，然后重启：

```bash
bash scripts/install_hik_camera_system.sh --install-udev --configure-usb-buffer \
  --workspace /home/bean/smart_car_robot
sudo reboot
```

## 2. 采集验证

```bash
ros2 launch hik_camera_bringup hik_camera.launch.py \
  use_cpu_affinity:=true camera_cpu_core:=2

ros2 topic echo --once /hik_monocular/camera_info
ros2 topic hz /hik_monocular/image_raw
```

配置固定使用原始 MJPEG `1920×1080@30 fps` 与 `mmap` 采集。桥接节点只向 `/hik_monocular/image_raw` 输出通过校验且可解码的 `bgr8` 图像。连续测量 `60 s` 后，主图像平均频率不得低于 `28 fps`。

若 `rqt_image_view` 没有画面，先用以下命令区分采集、解码和图形显示问题：

```bash
ros2 node list | grep -E 'usb_cam|hik_mjpeg_decoder_node'
ros2 topic echo --once /hik_monocular/image_raw --field encoding
ros2 topic echo --once /hik_monocular/image_raw --field width
ros2 topic echo --once /hik_monocular/image_raw --field height
```

期望依次看到两个节点、`bgr8`、`1920` 和 `1080`。若桥接节点持续报告“未包含完整 JPEG 起止标记”或“无法解码”，保留终端日志，不要改回 `mjpeg2rgb`；这表示相机驱动缓冲与解码器之间仍有待定位的问题。

## 3. 标定

使用 [A4 标定板](../../../docs/camera/hik_monocular_chessboard.pdf) 打印件。打印时必须选择 `100%` 缩放，并用尺子确认每格为 `25 mm`。该图案有 `8×6` 个内部角点。

```bash
ros2 run camera_calibration cameracalibrator \
  --size 8x6 --square 0.025 \
  image:=/hik_monocular/image_raw camera:=/hik_monocular
```

标定完成后，把生成的真实参数替换 `camera_info/hik_monocular_calibration.yaml`。在此之前，该文件包含零内参，禁止用于感知、测距、建图或避障。

## 4. 可选 Web 预览

```bash
ros2 launch hik_camera_bringup hik_camera.launch.py \
  use_web_preview:=true use_cpu_affinity:=true camera_cpu_core:=2
```

浏览器访问：

```text
http://<树莓派 IP>:8080/stream?topic=/hik_monocular/image_raw&width=640&height=360&quality=70&client_id=topside-camera
```

预览仅用于人工观察。若开启后主图像频率低于 `28 fps`、出现持续丢帧或 CPU 超标，立即关闭 `use_web_preview`，仅保留 ROS 感知链路。
