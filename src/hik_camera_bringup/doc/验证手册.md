# 海康 USB 单目相机验证手册

本包封装 `usb_cam` 采集配置和 MJPEG 解码桥接节点。稳定设备别名为 `/dev/hik_monocular`：两个节点在同一多线程组件容器内通过进程内通信传递原始 MJPEG，避免 `1920×1080` 大帧跨 DDS 拷贝。`usb_cam` 的内部接口为 `/hik_monocular/driver/image_raw` 和 `/hik_monocular/driver/camera_info`；桥接节点校验 JPEG 起止标记、丢弃坏帧，再发布对外的原生压缩图像、按需 BGR 图像和相机内参。

## 1. 前置条件

树莓派上安装驱动与标定工具：

```bash
sudo apt install -y ros-jazzy-usb-cam ros-jazzy-camera-calibration \
  ros-jazzy-web-video-server ros-jazzy-image-transport-plugins
```

首次部署时安装设备别名和 USB 缓冲参数，然后重启：

```bash
bash scripts/install_hik_camera_system.sh --install-udev --configure-usb-buffer \
  --workspace /home/bean/smart_car_robot
sudo reboot
```

该规则除 VID、PID 和序列号外还限制 `ID_V4L_CAPABILITIES` 必须包含
`capture`，避免同一 USB 相机暴露的非采集 `/dev/video*` 节点覆盖
`/dev/hik_monocular`。重启后应验证：

```bash
readlink -f /dev/hik_monocular
udevadm info --query=property --name=/dev/hik_monocular | \
  grep '^ID_V4L_CAPABILITIES=.*capture'
```

## 2. 采集验证

```bash
ros2 launch hik_camera_bringup hik_camera.launch.py \
  use_cpu_affinity:=true camera_cpu_core:=2

ros2 topic echo --once /hik_monocular/camera_info
ros2 topic hz /hik_monocular/image_raw/compressed
```

配置固定使用原始 MJPEG `1920×1080@30 fps` 与 `mmap` 采集。桥接节点只向 `/hik_monocular/image_raw/compressed` 输出通过校验的原生 JPEG；该话题连续测量 `60 s` 后平均频率不得低于 `28 fps`。当且仅当感知、标定等节点订阅 `/hik_monocular/image_raw` 时，桥接才解码并发布 `bgr8` 图像。

若 `rqt_image_view` 没有画面，先用以下命令区分采集、解码和图形显示问题：

```bash
ros2 node list | grep -E 'usb_cam|hik_mjpeg_decoder_node'
ros2 topic echo --once /hik_monocular/image_raw/compressed --field format
ros2 topic hz /hik_monocular/image_raw/compressed
```

期望依次看到两个节点、`jpeg` 和接近 `30 fps` 的频率。使用 `rqt_image_view` 时，在话题列表选择 `/hik_monocular/image_raw` 的 `compressed` 传输（通常显示为 `/hik_monocular/image_raw/compressed`），不要选择默认 `raw`。若桥接节点持续报告“未包含完整 JPEG 起止标记”或“无法解码”，保留终端日志，不要改回 `mjpeg2rgb`；这表示相机驱动缓冲与解码器之间仍有待定位的问题。

## 3. 标定

使用 [A4 标定板](../../../docs/camera/hik_monocular_chessboard.pdf) 打印件。打印时必须选择 `100%` 缩放，并用尺子确认每格为 `25 mm`。该图案有 `8×6` 个内部角点。

```bash
ros2 run camera_calibration cameracalibrator \
  --size 8x6 --square 0.025 \
  image:=/hik_monocular/image_raw camera:=/hik_monocular
```

标定完成后，把生成的真实参数替换 `camera_info/hik_monocular_calibration.yaml`。在此之前，该文件包含零内参，禁止用于感知、测距、建图或避障。

## 4. 可选 Web 预览

```bash
ros2 launch hik_camera_bringup hik_camera.launch.py \
  use_web_preview:=true use_cpu_affinity:=true camera_cpu_core:=2
```

浏览器访问：

```text
http://<树莓派 IP>:8080/stream?topic=/hik_monocular/image_raw&width=640&height=360&quality=70&client_id=topside-camera
```

预览仅用于人工观察。若开启后主图像频率低于 `28 fps`、出现持续丢帧或 CPU 超标，立即关闭 `use_web_preview`，仅保留 ROS 感知链路。
