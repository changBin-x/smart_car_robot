## 2. 协议形式（重要特征）

- **纯 ASCII 文本协议**，不是二进制帧。
- 每条指令/应答以 `$` 开头、`#` 结尾，字段间用 `,` 分隔，**无 CRC/校验字节**。
- 帧完整性只能靠 `$...#` 定界判断：解析时按 `#` 切分、丢弃不完整/无法解析的段。
- 指令大小写均可；配置类指令成功后回 `指令+OK`（如 `$mtype:2#OK`），**`$spd` / `$pwm` 无应答**。
- 电机接口与车轮对应关系（固件固定）：

| 板载接口 | 车轮 | 本项目关节名 |
|---|---|---|
| M1 | 左前轮 | `front_left_wheel_joint` |
| M2 | 左后轮 | `rear_left_wheel_joint` |
| M3 | 右前轮 | `front_right_wheel_joint` |
| M4 | 右后轮 | `rear_right_wheel_joint` |

## 3. 指令一览（帧格式表）

ASCII 协议没有"帧头/功能码/校验"的二进制概念，对应关系为：帧头=`$`，功能码=指令名，帧尾=`#`，校验=无。

### 3.1 配置类（断电保存，只需配置一次）

| 指令 | 功能 | 例子 | 默认值 | 应答 |
|---|---|---|---|---|
| `$mtype:x#` | 电机类型：1=520, 2=**310**, 3=TT带编码器, 4=TT无编码器 | `$mtype:2#` | 520 | `+OK` |
| `$deadzone:xxxx#` | PWM 死区（0–3600），实测得出 | `$deadzone:1300#` | 1600 | `+OK` |
| `$mline:xx#` | 霍尔编码器相位线数（磁环线数） | `$mline:13#` | 11 | `+OK` |
| `$mphase:xx#` | 减速比 | `$mphase:20#` | 30 | `+OK` |
| `$wdiameter:xx#` | 轮子直径 mm（影响速度类数据换算） | `$wdiameter:48.00#` | 67 | `+OK` |
| `$MPID:p,i,d#` | 速度环 PID（写入后芯片重启） | `$MPID:0.8,0.06,0.5#` | P0.8 I0.06 D0.5 | `+OK` |
| `$flash_reset#` | 恢复出厂设置（模块重启） | — | — | `+OK` |

310 电机（本项目 M310）推荐配置（来自 `rpi_USART_example.py` MOTOR_TYPE==2 分支）：
`mtype=2, mphase=20, mline=13, wdiameter=48.00, deadzone=1300`。

### 3.2 控制类（无应答，不保存）

| 指令 | 功能 | 范围 | 例子 |
|---|---|---|---|
| `$spd:m1,m2,m3,m4#` | 4 电机闭环速度控制 | −1000 ~ 1000（单位 mm/s，见 §5） | `$spd:100,-100,0,50#` |
| `$pwm:m1,m2,m3,m4#` | 4 电机开环 PWM | −3600 ~ 3600 | `$pwm:0,0,0,0#` |

注意：`$spd:0,0,0,0#` 时 PID 仍在工作（手拧不动轮子）；要完全释放电机用 `$pwm:0,0,0,0#`。
**停机指令**：先发 `$spd:0,0,0,0#`（刹停），必要时再 `$pwm:0,0,0,0#`（释放）。

### 3.3 数据上报（读取编码器/速度）

开关指令：`$upload:a,b,c#`，三个开关位分别控制三种周期上报（1=开 0=关），可同时开多路：

| 开关位 | 上报内容 | 应答帧格式 | 数据含义 |
|---|---|---|---|
| a | 轮子总编码器计数（累计位置） | `$MAll:m1,m2,m3,m4#` | 整数，累计编码器计数 |
| b | 实时增量编码器计数 | `$MTEP:m1,m2,m3,m4#` | 整数，**每 10 ms 周期内的脉冲增量** |
| c | 轮子当前速度 | `$MSPD:m1,m2,m3,m4#` | 数值（可含小数），单位 **mm/s** |

例：`$upload:1,0,1#` = 同时上报总编码器计数 + 当前速度。
上报为周期性主动推送（MTEP 注明周期 10 ms；MAll/MSPD 周期文档未单独注明，推测同为 10 ms）。

其他查询：`$read_flash#`（回读 flash 配置），`$read_vol#`（回 `$Battery:7.40V#`）。

## 5. 单位与换算公式

符号约定：
- `L` = 编码器基础线数（=13，参数 `encoder_lines`）
- `G` = 减速比（**已确认 20.0**，参数 `gear_ratio`）
- `K` = 编码器计数倍频系数（1/2/4，默认 1，实机标定，参数 `count_multiplier`）
- `CPR = L × G × K` = 输出轴每转一圈的编码器计数
- `r` = 轮半径 m（参数 `wheel_radius`）

### 5.1 位置（rad）← `$MAll` 累计计数 `n`

```
position [rad] = n / CPR × 2π = 2π·n / (L·G·K)
```

### 5.2 速度（rad/s）

方案 A —— 用 `$MTEP` 增量计数 `Δn`（每 10 ms）：

```
velocity [rad/s] = Δn / CPR × 2π / 0.01
```

方案 B —— 用 `$MSPD` 线速度 `v`（mm/s，依赖板内配置的轮径 `$wdiameter`）：

```
velocity [rad/s] = v / 1000 / r
```

方案 B 受板内 `wdiameter` 配置影响，且板内轮径与 URDF 轮半径必须一致才自洽；
**建议以方案 A（MTEP）或 MAll 差分为主**，MSPD 仅作参考（见问题 Q3）。

### 5.3 目标速度下发 ← ros2_control 的 velocity 命令（rad/s）

`$spd` 参数单位为 mm/s（板内按 `wdiameter` 换算，寄存器表注明"单位为 mm"）：

```
spd_value [mm/s] = ω [rad/s] × r [m] × 1000，限幅到 [-1000, 1000]
```

### 5.4 IIC 模式补充（本项目不用，仅记录）

IIC 地址 0x26；速度/PWM 寄存器 0x06/0x07 为 int16 **大端**；轮径寄存器 0x05 为 float **小端**；
编码器总计数 = `buf[0]<<24 | buf[1]<<16 | bf[0]<<8 | bf[1]`（两寄存器拼 32 位）。
串口 ASCII 协议无字节序问题。

## 6. 驱动板硬件要点（接线用）

- 供电 5–12 V（M310 额定 7.4 V，2S 锂电直供合适）；单路持续 4 A（峰值 5.5 A）。
- 每个电机两组线：XH2.54-2PIN 电机电源线 + PH2.0-6PIN 编码器线（电机−、编码器电源、A 相、B 相、编码器地、电机+）。
- 与树莓派仅需 Type-C 一根线（供串口通信；驱动板电源另接电池）。
- 若编码器 A/B 接反导致方向错乱，固件说明：310 电机应选 `$mtype:2#` 与其接线约定配套。

## 7. 确认结论（2026-07-17 已由项目负责人确认）

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 减速比取值（jpg 20.409 vs 例程 20） | **定为 20**：板内 `$mphase:20#`，驱动换算参数 `gear_ratio` 默认 20.0 |
| Q2 | 编码器计数倍频 K | 做成参数 `count_multiplier`，默认 1，实机转一圈标定后修正 |
| Q3 | 速度状态来源 | `$MTEP` 增量差分为主（方案 A），不依赖板内轮径 |
| Q4 | read() 策略 | 周期推送模式：取最新帧解析，连续 N 周期无新帧返回 ERROR（N 做成参数） |
| Q5 | 电机方向 | 参数 `wheel_direction_multipliers`（4 个 ±1，默认全 1），实机联调时校 |
| Q6 | 板内配置职责 | `on_configure` 每次下发全部配置指令（自愈式），参数来自 URDF `<param>` |
| Q7 | 轮子几何 | **麦轮直径 60 mm（半径 0.03 m）**；前后轮距、左右轮距暂用占位值，实测后替换 |
| Q8 | 无 CRC | 帧格式解析失败即视为校验失败丢帧，连续失败达阈值报 ERROR |
