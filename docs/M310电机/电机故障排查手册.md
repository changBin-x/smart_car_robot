# M310（MG310）电机不转故障排查手册

> 记录一次「电机通电不转、只发热并轻微抖动」的完整排查过程与结论。
> 适用对象：使用 MG310 霍尔编码器减速电机 + 4 路电机驱动板 + 树莓派 4B 的调试场景。
> 最终根因：**电机输出轴机械卡死（堵转）**。

## 1. 故障现象

在树莓派上通过 USB 串口（`/dev/ttyUSB0`，CH340）向 4 路电机驱动板下发指令，测试 Motor1 端口的 MG310 电机，观察到：

- 电机**完全不转**，仅在通电瞬间**轻微抖动一次**。
- 电机**发热**（说明绕组有电流通过）。
- 编码器上报正常（能收到 `$MAll` 帧），但计数几乎不变（个位数增量）。
- 闭环速度指令（`$spd`）和开环 PWM 指令（`$pwm`）都无法让电机转起来，即使 PWM 占空比给到 89%~100%。
- 排查过程中 CH340 曾一度从 USB 总线掉线（`/dev/ttyUSB0` 消失），重插 Type-C 后恢复。

## 2. 关键背景参数

来自 [M310电机参数资料.jpg](M310电机参数资料.jpg)：

| 参数 | 值 |
|---|---|
| 型号 | MG310（霍尔编码器） |
| 减速比 | 1:20.409 |
| 额定电压 | 7.4 V（建议 7–13 V） |
| 额定电流 | ≤ 500 mA |
| 堵转电流 | ≤ 2 A |
| **是否可堵转** | **NO（不可堵转）** |
| 减速后编码器线数 | 265.2 |

> **重要**：此电机**不可堵转**。堵转时电流可达 2 A，长时间堵转会热损伤电机。
> 排查时必须限制单次驱动时长并预留散热间隔。

电机接线为单根 6-pin PH2.0 排线，引脚定义（从最外侧数）：

| 引脚 | 定义 |
|---|---|
| 1（最外） | 电机线 −（M−） |
| 2 | 编码器电源 |
| 3 | 编码器输出 A 相 |
| 4 | 编码器输出 B 相 |
| 5 | 编码器地线 |
| 6（最外） | 电机线 +（M+） |

即：**电机动力线 M+/M− 是 6-pin 排线最外侧的两根**，通过随附的「ph2.0 转 XH2.54 排线」引到驱动板的 XH2.54 电机端子。

## 3. 排查过程（逐步二分定位）

排查遵循「从软件到硬件、逐层隔离」的思路，每一步都用测量数据排除一类可能。

### 3.1 排除软件层

- 驱动板配置指令（`$mtype`、`$mline`、`$mphase`、`$wdiameter`、`$deadzone`）全部返回 `OK`。
- 编码器数据上报（`$MAll`）正常。
- 电池电压查询 `$read_vol#` 返回 `$Battery:8.5V#`，正常。
- ROS 2 `motor_driver` 实机栈完整启动：插件加载、串口打开、`on_configure` / `on_activate` 成功，两个控制器均 active。

**结论**：软件、串口通信、驱动板固件均正常，故障在硬件侧。

### 3.2 排除 H 桥 / 驱动板功率级

用万用表 DC 电压档测量各点电压：

| 状态 | 电源输入端子 | 电机端子 M+/M− |
|---|---|---|
| 空闲、不插电机 | 8.5 V | 8.5 V（开路） |
| 空闲、插入电机 | 8.5 V | 6.118 V |
| 开环驱动 PWM=2500/3600 | 8.4 V（稳定） | −7.8 V |

- 驱动时电源输入端稳定在 8.4 V，**未塌陷** → 排除「电源供流不足」。
- 驱动时电机端子达到 −7.8 V（接近满压）→ 排除「H 桥故障 / 功率级高阻」。

**结论**：驱动板 H 桥正常，电机确实拿到了约 7.8 V 驱动电压。

> 说明：电压符号为负（−7.8 V）只是驱动板内部「正 `spd` → 负极性输出」的接线约定，非故障。

### 3.3 隔离电机本体

将电机从驱动板拔下，完全断电后测量：

- **绕组电阻**：万用表电阻档测 M+/M−（6-pin 最外两根）之间，读数**几欧姆** → 绕组健康（无短路、无开路）。
- **手动转动输出轴**：输出轴转不动。

> 注意：MG310 是 1:20.409 减速电机，正常情况下从输出轴端手动反向转动本就困难（大减速比 + 齿轮啮合摩擦）。但结合「通电 7.8 V、绕组正常、有电流发热、却只抖一下不转」，判定为**输出轴/减速箱机械卡死**。

## 4. 根因

**电机输出轴机械卡死（堵转）。** 电气部分全部正常（绕组几欧姆、能拿到 7.8 V 驱动电压、通电有电流），但转子/减速箱被卡住，电机无法旋转。持续通电只会让绕组发热（大电流），并因大电流拉垮 Type-C 供电导致 CH340 掉线。

**处理**：解除输出轴 / 减速箱的机械卡阻后，电机恢复正常转动。

## 5. 诊断结论速查表

| 观测量 | 正常值 | 本次实测 | 判读 |
|---|---|---|---|
| 配置指令应答 | `OK` | `OK` | 通信正常 |
| 电池电压 `$read_vol` | ≈ 电源电压 | 8.5 V | 电源正常 |
| 电源端子（驱动时） | 稳定不塌 | 8.4 V | 供电充足 |
| 电机端子（驱动时） | 接近电源电压 | −7.8 V | H 桥正常 |
| 绕组电阻 M+/M− | 几欧姆 | 几欧姆 | 绕组健康 |
| 手转输出轴 | 减速电机本就难转 | 转不动 | 疑似卡死 |
| 通电表现 | 持续旋转 | 抖一下 + 发热不转 | **机械卡死** |

## 6. 排查方法论（可复用）

按此顺序逐层隔离，能快速定位「电机不转」类故障：

1. **软件层**：配置应答是否 OK、编码器是否上报、电池电压是否正常。
2. **H 桥 / 功率级**：驱动时测**电源输入端子**电压是否塌陷（塌 → 电源问题；稳 → 往下查）。
3. **驱动输出**：驱动时测**电机端子**电压是否接近电源电压（低 → 动力线虚接 / H 桥故障；正常 → 往下查）。
4. **电机本体**：断电后测**绕组电阻**（几欧姆正常；0 → 短路；无穷大 → 开路），手动转轴判断机械卡死。

## 7. 安全注意事项

- MG310 **不可堵转**，排查时单次驱动 ≤ 6 秒并预留散热间隔，避免绕组热损伤。
- 通过 Type-C 单线同时供电与通信时，电机大电流可能拉垮 5 V 供电导致 CH340（串口芯片）掉线。建议电机功率由**独立电源**（如 2S 锂电）供电，Type-C 仅负责通信。
- 任何测试脚本都要有兜底停车逻辑：结束时下发 `$spd:0,0,0,0#` 与 `$pwm:0,0,0,0#`，并关闭数据上报 `$upload:0,0,0#`。
